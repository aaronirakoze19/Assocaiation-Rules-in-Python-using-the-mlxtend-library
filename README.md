# Assocaiation-Rules-in-Python-using-the-mlxtend-library


Pandas – for data manipulation and DataFrame handling
mlxtend – for implementing Apriori algorithm and association rule mining
Jupyter Notebook – for running and documenting the analysis

This project demonstrates Market Basket Analysis — a data mining technique used to identify relationships between items purchased together. This notebook demonstrates how to perform Market Basket Analysis using the Apriori algorithm from the mlxtend library. The goal is to find patterns and associations between products frequently bought together, using a small sample dataset
The implementation uses the mlxtend library in Python to generate frequent itemsets and association rules from a sample shopping basket dataset.
